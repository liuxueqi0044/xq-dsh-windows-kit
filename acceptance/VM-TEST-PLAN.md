# Windows 11 VM 测试计划（M11）

本计划只在两台隔离、可回滚的 Windows 11 x64 干净 VM 执行：`zh-CN` 与 `en-US`。每项由执行者操作、复核者独立检查；二者不得为同一人。VM 无生产数据、私人仓库或真实长期凭据，使用限额临时测试账号，Key 由执行者本人在 DSH 界面输入。

证据包每项包含：ID、VM 快照/标识、OS build/locale、产品/DSH 版本、UTC 起止时间、命令与期望/实际、执行者、复核者，以及截图/日志摘要 SHA-256。原始证据先脱敏再哈希；不得保存 Key、Token、Cookie、会话正文或工作区内容。复核者重新计算 hash 并确认文件未被替换。

| ID | 操作（两台 VM 均执行，除非注明） | 证据与验收 | 隐私/哈希要求 |
|---|---|---|---|
| VM-001 | 建立 zh-CN 与 en-US 干净快照，记录 VM 标识、locale、OS build、x64 | 两份独立初始化记录 | 不含主机用户资料；记录摘要 hash |
| VM-002 | 安装支持的 Node 22.19+（22.x）或 24.x；运行环境检查 | 环境检查输出、Node/npm/npx 版本与退出码 | 输出脱敏后保存并哈希 |
| VM-003 | 核对 manifest 固定包、官方 registry、tarball/integrity/SHA/commit/license；执行锁定 DSH 启动 | 供应链 observation 与启动命令、版本证据 | 不记录 Key；原始网络输出脱敏后 hash |
| VM-004 | 在 Documents 下创建专用窄空目录，拒绝桌面、用户根、磁盘根和非空目录 | 规范化路径、目录为空证据、用户确认记录 | 不列出工作区文件内容；截图 hash |
| VM-005 | 由执行者本人在本机 Web UI 输入临时 Key；验证 XQ/客服未接触明文 | 操作记录与无明文扫描结果 | Key 不截图、不入日志；证据包二次扫描并 hash |
| VM-006 | 以 `workspace-write + ask` 执行 hello.txt 受控读写；拒绝删除/凭据/系统设置 | 审批截图、文件摘要、退出结果 | 仅测试样例；不上传工作区 |
| VM-007 | 检查 3080 IPv4/IPv6 监听，确认仅 `127.0.0.1`，无 `0.0.0.0`/公网 | netstat/PowerShell 监听证据、PID 归属 | 脱敏 PID/路径；日志 hash |
| VM-008 | 停止、重启 DSH，核对 Profile/测试文件行为与指南一致 | 停止/重启日志、前后 hash、截图 | 不收集会话正文；证据 hash |
| VM-009 | 分别模拟 API 失败、3080 占用、网络/下载失败，确认友好非零退出且不破坏进程 | 每种故障的命令、退出码和恢复记录 | 不包含真实 URL token；摘要 hash |
| VM-010 | 安装无代码执行测试 Skill，确认 catalog/最小调用，再停用删除 | 来源、版本、目录、发现/删除证据 | 只用无敏感夹具；截图/日志 hash |
| VM-011 | 备份 Profile；安装无外部账号预构建插件；dump-config/boot/最小验证；模拟失败回滚并删除 | 备份、integrity、回滚前后 hash、监听复核 | 禁止 allowBuilds/未知脚本；不收集配置值 |
| VM-012 | 运行只读诊断，人工检查字段并扫描假 Key/JWT/Cookie/URL Token | 报告、脱敏扫描零命中、人工复核记录 | 报告不得含凭据/会话/工作区内容；文件 hash |
| VM-013 | 在断网条件打开全部离线页面；扫描 ZIP 白名单、敏感文件和 SHA256SUMS | 断网截图、ZIP 清单、外部/内部 hash 对照 | ZIP 不含测试夹具、Key、staging；证据 hash |
| VM-014 | 执行者提交完整证据索引；独立复核者逐项复算 hash、检查品牌/售后/已知问题 | 双人签字记录、未决项清单 | 执行者与复核者身份分离；无真实凭据 |

## 判定与保留

任一 VM 项缺证据、hash 不一致、泄露秘密、执行者与复核者相同、失败未回滚或出现未知网络行为，即为 FAIL 或 PENDING，不得补写为 PASS。VM 证据只引用临时账号和测试样例。VM-001…014 全部 PASS 仍不能替代 M10 GitHub main 实际绿色 run；所有必需项完成前 manifest 保持 `draft`。
