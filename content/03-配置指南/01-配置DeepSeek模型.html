配置 DeepSeek 模型

本页说明如何在本机 Web UI 中配置一个用户自己的 DeepSeek API 账号；具体字段以锁定版本界面为准。

Key 规则：API Key 和调用费用不包含在本商品内。只能由用户本人在自己的电脑输入 Key；不要把完整 Key、Token、Cookie 或一次性 URL 发送给客服，也不要写入 HTML、脚本或诊断报告。
  1. 启动本机 UI 后，确认地址栏为 127.0.0.1:3080。
  2. 在模型/凭据设置中由本人粘贴 Key，确认保存范围和数据处理提示。
  3. 选择兼容的 DeepSeek 模型，先不要启用未知插件、联网扩展或上传功能。
  4. 保存后用无敏感数据的低风险任务验证；失败时停止并运行只读诊断。

本指南不承诺价格、配额或模型可用性；这些由 DeepSeek 账号和服务条款决定。
