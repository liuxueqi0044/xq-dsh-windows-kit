# 执行分工与模块施工合同

状态：`ARCHITECTURE-FROZEN`。M01–M11 已按本分工形成开发实现基线；真实 DSH、GitHub main、中英文 VM 与双人发布门禁仍按本文件的 fail-closed 规则执行。

## 1. 角色

| 角色 | 建议模型 | 职责 |
|---|---|---|
| 总架构师/集成人 | Sol | 架构、关键安全决策、供应链结论、代码复核、集成与发布判断 |
| Runtime 员工 | `gpt-5.6-terra` | M03、M04、M05、M06 |
| Build 员工 | `gpt-5.6-terra` | M01 Schema 实现、M02、M09、M10 的构建部分 |
| Content/QA 员工 | `gpt-5.6-luna` | M07、测试夹具、验收表机械化、离线扫描样例 |
| Extension 员工 | `gpt-5.6-terra`，第二波复用 | M08；在基础安全内核稳定后开始 |

每个员工使用 `fork_turns: none` 或最小必要上下文，只收到自己的模块文档、相关 Schema 和验收 ID，避免完整对话成本。

## 2. 实施波次

### 波次 0：Sol 架构冻结

完成 M01–M11 模块合同、总体验收矩阵、安全边界和上游未知项列表。此时不写业务实现。

### 波次 1：基础层并行

- Terra Build：M01、M02。
- Terra Runtime：M03。
- Luna Content：M07 初稿与 HTML 测试夹具。
- Sol：核验 CLI 与供应链证据，审查公共接口。

### 波次 2：功能层并行

- Terra Runtime：M04、M05、M06。
- Terra Build：M09、M10。
- Terra Extension：M08。
- Luna：补齐内容、FAQ、验收数据和负向夹具。

### 波次 3：集成

Sol 合并接口、运行全部自动化测试、审查差异、生成候选包。员工不能自行宣布项目完成。

### 波次 4：外部门禁

按 M11 在中英文 Windows 11 VM 执行。需要真实测试账号、GitHub `main` Actions 和人工证据，无法在普通本机单元测试中替代。

## 3. 员工任务输入

每个任务必须包含：

- 模块编号和允许编辑的目录；
- 上游与产品版本；
- 输入/输出文件；
- 可调用的公共接口；
- 不得修改的安全规则；
- 必须通过的验收 ID；
- 本地验证命令；
- 完成时的变更清单和残余风险模板。

## 4. 员工完成定义

模块员工只有在以下条件全部满足时才能报告“模块候选完成”：

1. 只修改获准目录；
2. 所有约定输出存在；
3. 自测命令实际运行；
4. 对应验收 ID 有结果；
5. 没有把 `PENDING` 写成 `PASS`；
6. 未绕过公共安全内核；
7. 提交变更摘要、测试输出摘要和已知限制。

“代码看起来正确”不构成完成证据。

## 5. Sol 复核门

每个模块合入前检查：

- 接口是否与 M01/M03 一致；
- 是否出现重复安全逻辑；
- 是否扩大网络、文件系统或进程权限；
- 是否存在未经确认的写入；
- 错误信息是否泄露敏感内容；
- 负向测试是否真的触发失败；
- 文档能力声明是否超过实际实现。

高风险模块 M02、M03、M05、M06、M08、M09 必须由 Sol 阅读关键实现，不只查看测试结果。

## 6. 目录所有权

| 模块 | 首选编辑目录 | 禁止跨越 |
|---|---|---|
| M01 | `manifest/`、`governance/`、`schemas/` | 不改运行脚本 |
| M02 | `build/Resolve-*`、`build/Verify-*` | 不改 manifest 锁值，除非单独批准 |
| M03 | `lib/` | 不产生外部状态 |
| M04–M05 | `launcher/` | 不改供应链实现 |
| M06 | `diagnostics/` | 不读取工作区内容 |
| M07 | `content/` | 不加远程资源或脚本 |
| M08 | `extensions/` | 不进入自助 ZIP |
| M09 | `build/`、布局清单 | 不复制白名单外文件 |
| M10 | `tests/`、`.github/workflows/` | 不弱化生产策略来迁就测试 |
| M11 | `acceptance/` | 不写真实 Key 或私人数据 |

## 7. 冲突处理

若员工发现模块合同与上游事实冲突，应停止相关实现并报告：事实证据、受影响验收 ID、可选方案及安全差异。员工不得自行放宽 host、registry、工作区、确认或发布门禁。
