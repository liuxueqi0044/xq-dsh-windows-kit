# M04 只读环境检查器

## 目标

在不改变系统的前提下，判断 Windows 11 x64 是否满足候选运行条件，并给出可脱敏保存的检查结果。

## 输入

- `-WorkspacePath`：可选，仅评估，不创建；
- `-OutputFormat Human|Json`；
- `-ManifestPath`：测试和开发可指定，商品入口使用随包清单；
- M03 公共模块。

## 输出

- 控制台人类可读检查表或 JSON；
- 退出码 0/2/3/5；
- 不默认写文件。

## 依赖与非职责

依赖 M01 和 M03。它不承担 Node 安装、PATH 修复、DSH 下载、Profile 初始化或端口清理；这些动作不能通过隐藏参数开启。

## 检查项

- Windows 产品名、版本/build 与 x64；
- 当前进程是否管理员，仅提示不要求提升；
- Node、npm、npx、pnpm 路径和版本；
- 3080 端口监听情况及 PID（如系统 API 可提供）；
- `dsh` 命令发现情况和只读版本结果；
- npm cache 中锁定顶层包的迹象，不访问网络；
- DSH Home/Profile 是否存在；
- 工作区是否为安全窄目录；
- 工作区所在卷可用空间。

检查命令必须有超时。错误只影响对应检查，不导致未经处理的脚本崩溃。

## 明确禁止

不安装 Node，不修改 PATH/ExecutionPolicy，不创建工作区，不结束端口进程，不删除 DSH 数据，不输出环境变量，不上传报告。

## 失败模式

单个只读探针超时或不可用时返回对应检查的 `UNKNOWN/BLOCKER`，其余检查继续。manifest 无效属于整体失败。机器输出不得混入未经结构化的命令 stderr。

## 验收标准

- `ENV-001`：Windows 11 x64 支持条件能正确判断。
- `ENV-002`：Windows 10、非 Windows 和非 x64 形成阻断项。
- `ENV-003`：Node 支持矩阵调用 M03，而非复制判断代码。
- `ENV-004`：npm/npx 缺失时给出友好阻断，不抛原始异常。
- `ENV-005`：pnpm 缺失仅按用途给出提示，不误报基础启动失败。
- `ENV-006`：端口占用时报告但不结束进程。
- `ENV-007`：npm cache 检查不触网、不安装、不清理。
- `ENV-008`：DSH Home 检查不读取凭据、会话或配置正文。
- `ENV-009`：工作区检查不创建或修改路径。
- `ENV-010`：JSON 输出不包含 API Key、完整环境变量或工作区内容。
- `ENV-011`：执行前后文件系统、PATH、ExecutionPolicy 和进程状态无工具导致的变化。
- `ENV-012`：阻断、警告和信息在机器输出中可区分。
- `ENV-013`：可用磁盘空间被报告，低于治理阈值时形成阻断或警告。
- `ENV-014`：管理员状态被报告，但工具不会请求或触发提权。
