# M07 离线中文内容

## 目标

提供断网可读、无远程资源、能力声明准确的中文操作指南，并映射到任务书规定的商品目录。

## 输出页面

- 开始页；
- 环境检查使用说明；
- 启动与停止；
- DeepSeek 模型配置、安全工作区、第一次任务、权限审批、更新备份回滚、FAQ；
- 诊断工具说明；
- Skill 范围、插件风险、每项 +¥5 边界；
- 自助版、远程版、提交问题前准备；
- README.txt、品牌与开发者预览风险声明。

## 输入、依赖与非职责

内容从 M01 的产品事实和治理范围取得版本、权限、价格边界与支持状态。M07 不自行发明命令参数，不包含安装执行逻辑，不嵌入远程内容，也不宣称尚未通过的门禁。

## 内容架构

所有页面使用同一套内联 CSS 设计语言，不共享运行时 JS。页面顶部显示当前位置、适用版本、非官方声明和风险级别；操作步骤包含“将发生什么”“用户需要确认什么”“如何停止/回滚”。

外部网址以纯文本来源形式展示，不使用可加载的外链。页面间只用相对链接。

## HTML 安全规则

禁止 `<script>`、`iframe`、远程 `href/src`、CSS `url()`、`@import`、远程字体、表单提交、meta refresh、统计像素和广告。允许内联 CSS、语义 HTML、相对页面链接和本地锚点。

## 文案边界

必须使用“兼容/基于 DeepSeek Harness”，不得使用“官方安装器”“官方 Agent”“绝对安全”“不会误删”。明确 API Key 和费用不包含，用户本人输入 Key，DSH 是开发者预览版，Windows 沙箱不是绝对隔离。

## 失败模式

缺页、事实与 manifest 不一致、外链、脚本、错误品牌表述或未展示关键风险均阻断 M09。视觉问题在双语 VM 中记录为 FAIL，而不是仅作为建议。

## 验收标准

- `DOC-001`：任务书规定的每个页面均存在且标题正确。
- `DOC-002`：断网打开时正文、样式和内部导航可用。
- `DOC-003`：不存在远程资源、外链、脚本、iframe、统计或广告。
- `DOC-004`：不存在 DeepSeek Logo 或易造成官方背书的表述。
- `DOC-005`：非官方声明在开始页和关键风险页可见。
- `DOC-006`：Node、DSH 版本、host、port、权限与 manifest 一致。
- `DOC-007`：自助/远程/+¥5 服务边界与 governance 一致。
- `DOC-008`：API Key 由用户本人输入且不发送给客服。
- `DOC-009`：第一次任务只包含低风险样例读写，不含删除、凭据读取和系统设置。
- `DOC-010`：更新、备份、停止、卸载和回滚均有明确步骤。
- `DOC-011`：已知限制与 `draft/candidate` 状态准确展示。
- `DOC-012`：中文 Windows 11 VM 中无乱码、无截断、代码块可复制。
